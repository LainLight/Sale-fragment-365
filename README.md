## Что обновили

- Добавили веб-интерфейс с формой — можно вручную подставить сид-фразу, адрес NFT, цену, время аукциона и другие параметры.
- Запуск через Express (`npm start`) открывает страницу на `http://localhost:3000`.
- Значения по умолчанию (endpoint, длительность, комиссия и т.д.) подставляются из `.env` или стандартов скрипта.
- Старый CLI-скрипт `sell.js` оставили, но теперь он экспортирует функцию, которой пользуется веб.

## Быстрый старт

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте `.env` (пример ниже) или заполните данные прямо в форме.

3. Запустите сервер:

   ```bash
   npm start
   ```

4. Откройте `http://localhost:3000`, заполните форму и отправьте транзакцию.

> **Важно:** сид-фраза из `.env` не отображается на странице — при необходимости введите её вручную.

## Переменные окружения (`.env`)

```env
MNEMONIC="слова сид фразы через пробел"
NFT_ADDRESS=EQA...
PRICE_TON=500
DURATION=31536000
MIN_BID_STEP=5
MIN_EXTEND_TIME=3600
QUERY_ID=13
BENEFICIARY_ADDRESS=EQB...
TON_ENDPOINT=https://toncenter.com/api/v2/jsonRPC
TON_API_KEY=
TRANSFER_VALUE=0.1
PORT=3000
```

Любую из переменных можно не задавать и указать вручную в форме. CLI-режим (`npm run sell`) продолжает работать и подтягивает значения из `.env`.
