## Что внутри

- Выставление Telegram username (NFT) на продажу через Fragment.
- Продажа на срок до **365 дней (1 год)** — через контракт fixed-price аукциона.
- Теперь есть **веб-интерфейс**: можно подставлять сид-фразу, цену, адрес NFT и любые параметры прямо в браузере.

## Как запустить

1. Установи зависимости:
   ```bash
   npm install
   ```
2. Запусти сервер и фронтенд:
   ```bash
   npm start
   ```
3. Открой [http://localhost:3000](http://localhost:3000) и заполни форму.
4. Нажми «Выставить на продажу», чтобы отправить транзакцию.

> ⚠️ Убедись, что endpoint и API Key (если нужен) корректны, а на кошельке достаточно TON.

## Переменные окружения

Можно заранее прописать значения в `.env` (они станут дефолтами для формы):

| Переменная             | Что задаёт                                 |
| ---------------------- | ------------------------------------------ |
| `PORT`                 | Порт веб-сервера (по умолчанию `3000`).    |
| `TON_ENDPOINT`         | RPC endpoint, например TonCenter.          |
| `TON_API_KEY`          | Ключ для TonCenter, если требуется.        |
| `TON_MNEMONIC`         | Сид-фраза кошелька (через пробел).         |
| `NFT_ADDRESS`          | Адрес NFT (TON).                           |
| `SALE_PRICE`           | Цена продажи в TON.                        |
| `SALE_MAX_BID`         | Максимальная ставка (если отличается).     |
| `SALE_MIN_BID_STEP`    | Шаг повышения ставки (0-255).              |
| `SALE_MIN_EXTEND_TIME` | Продление аукциона при новой ставке (сек). |
| `SALE_DURATION`        | Общая длительность продажи (сек).          |
| `SALE_TRANSFER_TON`    | Сколько TON отправлять с сообщением.       |
| `SALE_QUERY_ID`        | Query ID, 64-битное число.                 |
| `SALE_BENEFICIARY`     | Адрес получателя средств (по умолчанию сам кошелёк). |
